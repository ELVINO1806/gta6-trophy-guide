Leonida Trophy Ledger — an offline tracker and guide for all 55 GTA 6 PlayStation 5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden). Every trophy has a guide written in plain words with cited sources, a 7-stage platinum roadmap, a missables page flagging the one missable trophy (Positive Mental Attitude, 18 meditation spots, Chapter 1 only), 10 filters, search, a spoiler mask, count steppers for the 21 tracked trophies, and progress that saves in the browser with export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or hand it in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
