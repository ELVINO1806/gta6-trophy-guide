Leonida Trophy Ledger — an offline tracker and guide for all 55 GTA 6 PlayStation 5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden). It ships a 7-stage platinum roadmap, flags the one missable trophy (Positive Mental Attitude, 18 meditation spots, Chapter 1 only), tracks progress with count steppers for the 21 counted trophies, hides story spoilers on demand, saves progress in the browser with export and import, and gives every trophy a cited guide (110 citations across Exophase, PSNProfiles, PowerPyx, GTABase, Beebom, TechWiser, EGamers, Boosting Factory, and HowToVideoGame). No network is needed to use it.

## Run it

```sh
node serve.ts 8080
```

Then open http://localhost:8080. The hand-in program is main.ts: it copies app/ and screenshots/ to the output directory and writes dossier.json there (set MAKEFUN_OUTPUT_DIR to choose where).
